СОЗДАТЬ ТЕРМИНАЛ

Новый терминал будет сохранён как черновик и не появится у игроков, пока вы не сделаете его активным.

СНЯТЬ ТЕРМИНАЛ С ЭФИРА?

Игроки перестанут видеть активный терминал. Трансляция, подключения, роли, назначения и сохранённый терминал останутся без изменений.

ЗАВЕРШИТЬ ТРАНСЛЯЦИЮ?

Активный терминал будет убран у всех игроков. Назначения персонажей и управление будут сброшены, а сессии и список персонажей сохранятся.

НАСТРОЙКИ ПУБЛИЧНОГО ДОСТУПА

Настройте ngrok и данные, которые игроки используют для входа.

СНАЧАЛА СОХРАНИТЕ ТОКЕН NGROK И ПАРОЛЬ ИГРОКОВ
КАК НАСТРОИТЬ ЧЕРЕЗ NGROK
  1. Создайте личный токен в своём аккаунте ngrok. Устанавливать ngrok или запускать Terminal не нужно.
  2. По умолчанию оставьте домен пустым: ngrok автоматически назначит случайный хост для публичной ссылки.
  3. Для фиксированного хоста укажите доступный вашему аккаунту домен без https://. Он начнёт использоваться только после сохранения настроек.
  4. Сохраните токен ngrok, затем откройте ИЗМЕНИТЬ ДАННЫЕ и задайте логин и пароль игроков от 8 символов либо сгенерируйте пароль.
  5. Сохраните настройки и включите доступ из основной панели.
  6. Дождитесь статуса ГОТОВ. Скопируйте URL и нажмите ПОДЕЛИТЬСЯ, чтобы получить логин и пароль, которые браузер запросит через Basic Auth.

Сохранённые токен и пароль не показываются: пароль обозначается маской ***** и попадает только в системный буфер после команды «Поделиться».
