# Tasks: Vue and TypeScript Frontend Migration

**Feature**: `033-frontend-vue-typescript-migration`
**Authoritative rollback source**: `06696ee1c7155a1bb1135ef46ec91445dd73a2a4`
**Execution rule**: run strictly by dependency and wave; a task completes only after its local verification and evidence. Later gates are additive.
**Path rule**: `Files` is the complete modifiable/create/delete inventory; `Read-only` is separately exact; `none` is an empty inventory.
**Parallelism**: no `[P]` tasks—each apparent branch shares a ledger row, legacy monolith, manifest, entrypoint, Taskfile section, generated tree, test configuration, or evidence record.
**ConnectRPC invariant**: all eight RPCs—`Subscribe`, `SelectCharacter`, `Navigate`, `Guess`, `ActivatePattern`, `SetPresentation`, `PresentationUplink`, and `SoundManifest`—retain service paths, messages, field numbers, protobuf authority, binary encoding, cardinalities, Connect errors, typed results, request limits, authorization, capability boundaries, snapshot/revision semantics, snapshot-first streaming, reconnect, backpressure, cancellation, and unary fallback without change.
