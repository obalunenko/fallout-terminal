## Description

T085 requires take-off-air and end-broadcast confirmations to ignore stale completions, resolve exactly once, and restore focus safely, but marks `useBroadcastControls.ts` read-only. T084 necessarily establishes confirmation request state before the dialogs mount; T085 is the first slice that can exercise completion-versus-cancel, newer-revision, and unmount races and therefore must finalize lifecycle applicability in that composable.
