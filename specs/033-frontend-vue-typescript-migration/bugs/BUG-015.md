**Type**: Implementation drift
**Severity**: High
**Feature**: `033-frontend-vue-typescript-migration`
**Reported**: 2026-08-31
**Status**: Patched
**Patched**: 2026-08-31

## Description

T074's first full browser run passed the new public-access ownership and secret-cleanup assertions but failed eight established parity journeys. One established fallback journey opens the raw production-coexistence fixture without importing the candidate entry, so the migrated panel is absent. The always-mounted generated-password dialog exposes its historical title as an accessible name while closed, causing the established `Новый пароль игроков` field locator to match both the hidden dialog and the password input. Finally, command-result projections from the settings and credential dialogs update a detached App snapshot while the panel URL/failure projections remain attached to `usePublicAccess`'s older snapshot; ordinary settings saves are routed through the legacy bridge but never applied back to that composable. This splits one public-access authority into inconsistent views and can retain a stale ready URL after a failure.

## Root Cause Analysis

The focused slice tests proved each leaf independently but did not exercise all command-result paths against the panel's derived URL/error state. App-level snapshot fan-in was added for credential dialogs without making the composable the same canonical owner, and the settings result continued to rely on a one-way legacy projection. The generated dialog remained mounted for cleanup/ownership evidence, unlike the former dynamic legacy node, which made its closed accessible name participate in field-label queries. One older multi-page fallback test also predated the per-spec candidate import added during the coexistence migration.

## Recommended Fix

1. Patch T074's writable inventory and add clarification notes without reopening completed focused slices.
2. Verify BUG-015 cross-artifact consistency.
3. Resume T074: mount the candidate in the fallback journey, suppress the generated dialog's accessible name while closed, and route every ordered public-access snapshot through `usePublicAccess`.
