**Type**: Spec conflict
**Severity**: High

**Reported**: 2026-08-31
**Status**: Patched
**Patched**: 2026-08-31

## Description

T080 creates `TerminalActionMenu.vue` and requires the terminal-row action trigger, validation, stale suppression, focus, complete action behavior, and mutual keyboard/outside-close behavior with the adjacent group menu to replace the temporary T078 placeholder. Its writable inventory omits `TerminalRow.vue`, where the placeholder is mounted; `useTerminalSelection.ts`, which validates the detached row projection needed to bind each action to the current revision and member position; and the existing `TerminalGroupList.vue`/`TerminalGroupRow.vue` shared menu-coordination owners.

Without those existing owners, the new component cannot mount in a terminal row or reject stale move/rename/delete requests without DOM inspection.

## Root Cause Analysis

Task generation treated the new action-menu SFC as self-mounting and did not carry forward the immediately preceding row/projection composition owners. The App/document seams added by BUG-017 cannot reach a per-row action trigger by themselves.

## Recommended Fix

1. Patch only T080's writable inventory and matching artifact notes with the row/projection and shared menu-coordination owners.
2. Verify task count, dependency order, and traceability remain unchanged.
3. Resume T080 with revision-bound row actions and exact placeholder removal.
