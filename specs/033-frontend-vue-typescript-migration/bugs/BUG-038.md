**Reported**: 2026-09-01
**Status**: Patched

## Description

The first complete Wave-H browser gate passes 223 tests and skips the two credential-qualified
ngrok tests, but 53 retained Player journeys fail after the candidate removal. Two injected-App
tests still set the deleted candidate globals and navigate to the ordinary production entry, so the
real RPC/storage adapters mount before their fakes. Two direct component fixtures retain the
pre-integration HackingSurface composition or omit TerminalRecord's final required page index.
Production journeys additionally expose cross-suite cutover gaps: observers never start the
reveal controller and therefore receive zero menu rows, the immutable `#screen` read-only contract
is attached only to an inner wrapper, the status-line text lost separator whitespace, pending
cross-terminal navigation is not projected as the legacy full-screen command surface, and sound
manifest requests are repeated while progressive reveal cues overlap initial preload.

## Root Cause Analysis

T156 proved deletion and production selection with two focused tests, but unlike the Overseer
cutover it did not migrate retained injected-App tests to a permanent production-root harness.
T163 then verified the dedicated visual/reveal matrix without running the complete behavioral
suite, leaving observer-only and historical selector contracts uncovered until T169.

## Recommended Fix

1. Add a browser-only fixture document and module that mount `mountPlayerApp` with injected public
   ports and expose exact-once unmount evidence without entering a production build or embed.
2. Migrate the two retained injected-App suites and update the two stale component fixtures to the
   final production components and required props.
3. Let observers participate in authoritative progressive reveal and restore the immutable screen
   read-only and status-line whitespace contracts; prove crafted observer clicks remain inert.
4. Project public pending terminal navigation through the shared record surface and deduplicate
   concurrent and completed manifest discovery per sound folder.
5. Run focused injected-App, component, observer, presentation, navigation, command, and visual
   regressions before rerunning `task browser:test`.
