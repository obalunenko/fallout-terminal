# BUG-001: Player candidate document cannot be built by its task-local Vite command

**Status**: Patched
**Reported**: 2026-08-30
**Patched**: 2026-08-30

## Problem

T041 required `frontend/client/test-fixtures/candidate-index.html`, but its exact Vite command builds `frontend/client/test-fixtures` as a root. Vite therefore looked for `frontend/client/test-fixtures/index.html` and failed with `UNRESOLVED_ENTRY`.

## Patch

Use `frontend/client/test-fixtures/index.html` as the isolated candidate document throughout the specification, plan, research, contracts, task inventory, ownership ledger, and implementation. This makes the wave-c candidate build configuration-neutral and leaves T107 responsible for later candidate-mode Vite and Playwright selection.

## Verification

Run T041's exact local command. The Player typecheck, isolated candidate build, and production-selection absence scan must all pass.
