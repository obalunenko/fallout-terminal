# Bug Report: Wave-e main-subtree slices omit their mounting and document owners

**Type**: Spec conflict
**Severity**: High
**Feature**: `033-frontend-vue-typescript-migration`
**Reported**: 2026-08-31
**Status**: Patched
**Patched**: 2026-08-31

## Description

Tasks T078–T082 each require a newly created terminal-sidebar, group-list, editor/settings, tree/node, or create-dialog slice to pass an immediate candidate browser assertion and remove its exact legacy renderer/markup. Their complete writable inventories omit `frontend/overseer/src/App.vue`, so none of the new slices can be mounted. The slices that replace production-document containers or dialog markup also omit `frontend/overseer/src/index.html`. T079 further cannot join its group renderer to the T078 sidebar because `TerminalSidebar.vue` is absent from its writable inventory.

Implementing the outcomes as written would require undeclared edits, leave the candidate assertion RED, or create duplicate/mixed DOM owners.

## Artifact Traceability

### spec.md

- **Affected user story**: User Story 2 — The Overseer retains every privileged control.
- **Affected requirements**: FR-002, FR-004, FR-006, FR-008, FR-022, FR-028, FR-031, FR-032, and FR-050; SC-001, SC-011, and SC-012.
- **Gap identified**: The requirements correctly mandate immediately verifiable component slices, typed state flow, and exclusive subtree ownership, while the task inventories prohibit the established App/document integration needed to achieve them.

### plan.md

- **Impact**: Clarify that every slice owns its existing App/document integration seam and that T079 may extend the immediately preceding sidebar composition.

### tasks.md

- **Affected tasks**: T078, T079, T080, T081, and T082.

## Root Cause Analysis

Task generation enumerated each new component/composable and the legacy JavaScript renderer but treated the already-established App/document seams as implicit. The repository path rule explicitly forbids that assumption, and immediate focused GREEN checks cannot observe unmounted SFCs.

## Recommended Fix

1. Patch only the five affected inventories and matching clarification notes.
2. Verify BUG-017 without changing task IDs, dependencies, or the Wave-e DAG.
3. Resume T078 and keep each slice independently GREEN.
