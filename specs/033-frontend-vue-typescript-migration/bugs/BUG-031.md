**Type**: Implementation drift
**Severity**: High

**Status**: Patched
**Patched**: 2026-08-31

## Description

The permanent production-root harness bypasses the terminal-grouping page's specialized import-map binding, so ordinary session saves and direct terminal activation use the generic fake instead of the fixture store. Separately, the typed controller's move/dissolve impact summaries omit unaffected resulting groups or reverse the established `group: members` presentation, and backend transition rejections expose internal IDs instead of terminal names.

## Root Cause Analysis

Vite resolves the production adapter binding alias before the fixture page's import map can select its route-specific module. The controller also generated move impact text from only the destination group and formatted dissolved singleton rows in reverse order.

## Recommended Fix

1. Preserve the specialized terminal-grouping save and activation fake commands in the permanent harness until T096.
2. Render every candidate group as `group: ordered members` for move and dissolution impacts.
3. Translate transition rejection terminal IDs into terminal names without exposing unsafe backend detail.
4. Rerun the complete grouping suite and T093 parity.
