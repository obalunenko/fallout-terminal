# Bug Report: Broadcast and hacking slices omit App/document integration owners

**Type**: Spec conflict
**Severity**: High
**Feature**: `033-frontend-vue-typescript-migration`
**Reported**: 2026-08-31
**Status**: Patched
**Patched**: 2026-08-31

## Description

T084–T086 each create a Vue component that must replace existing production-document controls or dialogs and pass an immediate candidate browser assertion. Their writable inventories omit `frontend/overseer/src/App.vue`, so the components cannot mount, and `frontend/overseer/src/index.html`, so the exact legacy markup cannot be replaced by Vue-owned targets or roots.

Without those integration owners, the tasks require undeclared edits, leave duplicate DOM owners, or cannot become observable in the candidate application.

## Artifact Traceability

### spec.md

- **Affected user story**: User Story 2 — The Overseer retains every privileged control.
- **Affected requirements**: FR-002, FR-004, FR-006, FR-008, FR-022, FR-028, and FR-050; SC-001 and SC-012.
- **Gap identified**: The required exclusive Vue ownership and immediate browser verification are correct, but the established App/document seams are absent from the task inventories.

### plan.md

- **Affected sections**: Wave e broadcast, confirmation-dialog, and Overseer hacking-control slices.
- **Impact**: Clarify that each slice owns its existing App/document integration seam while replacing the exact legacy subtree.

### tasks.md

- **Affected tasks**: T084, T085, and T086.
- **False completions**: None.
- **Missing tasks**: None. Add `App.vue` and `index.html` to each complete writable inventory.

## Root Cause Analysis

Task generation treated each new control/dialog SFC as self-mounting and did not carry forward the single App root and production-document owner required for exclusive rendering.

## Recommended Fix

1. Add only the established App/document integration seams to T084–T086.
2. Record matching spec, plan, and task clarification notes without changing task IDs or dependencies.
3. Resume T084 and require one owner for every migrated ID at each focused GREEN checkpoint.
