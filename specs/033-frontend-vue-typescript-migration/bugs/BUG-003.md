# Bug Report: T048 focused test does not load the Vue coexistence entry

**Type**: Spec conflict
**Severity**: High
**Feature**: 033-frontend-vue-typescript-migration
**Status**: Patched
**Reported**: 2026-08-30
**Patched**: 2026-08-30

## Description

T048's focused application-update test opens the Go fixture server's raw `frontend/overseer/src/index.html`. That server can execute the legacy JavaScript modules but cannot transform `main.ts`, Vue SFCs, or their module graph, so the Vue update subscription is never registered. The governed Vite candidate server is already running, but T048's inventory marks the test and candidate injection files read-only and therefore cannot connect the coexistence page to that compiled graph.

## Artifact Traceability

### spec.md

- **Affected user story**: User Story 2 — The Overseer retains every privileged control.
- **Affected requirements**: FR-030 and FR-031.
- **Gap identified**: The GREEN task's browser evidence cannot load the production Vue SFC graph at the point it runs.

### plan.md

- **Affected sections**: Browser fixture integration; Wave d — Overseer leaf components and composables.
- **Impact**: The test must use the governed Vite candidate entry/fake port for the Vue leaf while retaining the raw legacy page for adjacent coexistence controls.

### tasks.md

- **Affected task**: T048.
- **False completions**: None; T048 remains open.
- **Missing scope**: Add `frontend/overseer/test-fixtures/candidate-main.ts`, `frontend/overseer/test-fixtures/fake-desktop-port.ts`, and `tests/browser/application-update.spec.mjs` to T048's modifiable inventory.

## Root Cause Analysis

Task generation created the candidate route and the production coexistence root independently but did not assign the first GREEN leaf task the small injection seam needed to combine them. Raw fixture serving cannot compile SFCs, which the research artifact already identifies.

## Recommended Fix

1. Let the candidate entry mount the production App into either its isolated root or the coexistence leaf root.
2. Keep the typed fake port for the isolated candidate document, while selecting the already-loaded fixture-backed `DesktopPort` when the same entry mounts into the coexistence root.
3. Let the focused browser spec import that Vite-transformed entry into the coexistence page and drive the existing deterministic desktop fixture.
