# Bug Report: README lost required Wails cutover references

**Type**: Implementation drift
**Severity**: Medium
**Feature**: 033-frontend-vue-typescript-migration
**Reported**: 2026-08-31
**Status**: Patched
**Patched**: 2026-08-31

## Description

After the Wave-e scanner source assumptions were corrected, the real
`scripts/wails-v3-cutover-check.sh` gate reported that `README.md` no longer links the active
`specs/006-wails-v3-migration/quickstart.md`. The README still links the Wails v3 rollback document,
but it also no longer identifies the preserved Electron-to-Wails rollback record as historical.
Both references are established cutover invariants and their absence prevents T106 from passing.

- **Affected requirements**: FR-034, FR-035, FR-036, FR-040, FR-046; SC-010.

  scope for restoring its required active/historical links.

### plan.md

- **Impact**: The README must retain the active Wails v3 guide and distinguish the immutable
  Electron-to-Wails rollback record from the current Wails v3 rollback procedure.

### tasks.md

- **Affected task**: T106.

## Root Cause Analysis

A later README consolidation preserved the current rollback link but dropped the active Wails v3
quickstart and the historical rollback classification. The deterministic scanner correctly exposed
the documentation drift only after its earlier source-scan failure was fixed.

## Recommended Fix

1. Allow T106 to edit only the README documentation list.
2. Restore the active Wails v3 quickstart link.
3. Restore a clearly historical link to `docs/wails-migration-rollback.md` without modifying that
   completed historical document.
4. Rerun the Wails scanner self-test and real-tree gate.
