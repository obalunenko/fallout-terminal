# Bug Report: T054 cannot integrate or verify the terminal-switch leaf

**Type**: Spec conflict
**Severity**: High
**Feature**: 033-frontend-vue-typescript-migration
**Status**: Patched
**Reported**: 2026-08-30
**Patched**: 2026-08-30

## Description

T054 requires a Vue-owned terminal-switch dialog, removal of its legacy counterpart, and an exact focused browser GREEN result. The named browser spec does not yet exist, the legacy markup is owned by `index.html` outside the task inventory, the Vue application root and candidate entry are excluded, and switch requests originate from legacy activation results rather than a subscribed desktop event. The existing typed coexistence bridge must therefore carry the request into Vue, including in the raw browser fixture.

## Artifact Traceability

### spec.md

- **Affected user story**: User Story 2 — The Overseer retains every privileged control.
- **Affected requirements**: FR-004, FR-022, FR-028, FR-031, FR-032, and FR-050.
- **Gap identified**: The task cannot mount, receive, remove, or test the terminal-switch owner described by its outcome.

### plan.md

- **Affected section**: Wave d — Overseer leaf components and composables.
- **Impact**: The terminal-switch slice requires the existing App/index/candidate integration and typed coexistence bridge seam.

### tasks.md

- **Affected task**: T054.
- **False completions**: None; T054 remains open.
- **Missing scope**: Add `App.vue`, `index.html`, `main.ts`, `mount.ts`, `candidate-main.ts`, and the affected existing authoring regression to T054's modifiable inventory; create its already-declared focused spec.

## Root Cause Analysis

Task generation treated terminal switching like an event-backed approval leaf, but its request is a return value consumed by legacy orchestration. It also omitted the production-document owner of the dialog and assumed a focused spec already existed.

## Recommended Fix

Route the switch request over the typed coexistence bridge, mount that bridge in the governed candidate entry, remove the exact legacy markup and handlers, and add the focused plus existing authoring regressions without changing the wave DAG.
