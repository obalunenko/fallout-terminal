# Bug Report: Local Frontend Build Runs Before Node Version Validation

**Type**: Implementation drift

**Severity**: Low

**Feature**: `025-node-26-upgrade`

**Reported**: 2026-08-27

**Status**: Patched

**Patched**: 2026-08-27

**Verified**: 2026-08-27 — `task frontend:build` passed under Node.js 26.8.1 with zero `EBADENGINE` output; runtime-policy tests and static analysis passed.

## Description

`task frontend:build` can run under Node.js 26.7.0 even though every project-owned package requires Node.js 26.8.1 or newer. npm then emits repeated `EBADENGINE` warnings for the root package and both workspaces. The repository has no `.nvmrc` selector or Task preflight, and `CONTRIBUTING.md` still advertises Node.js 20.19+.

## Artifact Traceability

### spec.md

- **Affected user story**: User Story 1 — Use One Current Node.js Runtime
- **Affected requirements**: FR-001, FR-005, FR-008
- **Affected success criteria**: SC-003, SC-006
- **Gap identified**: The supported runtime is declared, but local Task workflows do not validate it before invoking npm and active contributor guidance is inconsistent.

### plan.md

- **Affected sections**: Implementation Approach; Validation Strategy
- **Impact**: Add a repository-local NVM selector, an early Task runtime check, and active documentation coverage.

### tasks.md

- **Affected tasks**: T001, T002, T004, T008
- **False completions**: None; their original surfaces passed, but local runtime selection and preflight were omitted.
- **Missing tasks**: Add regression assertions and implement the local version selector, preflight, and contributor correction.

## Root Cause Analysis

The upgrade aligned package engines, lockfiles, README, and automation but did not govern the runtime selected by local Task commands. npm treats an engine mismatch as a warning by default, so the build continued and repeated one warning for each project-owned package record.

## Recommended Fix

1. Add `.nvmrc` containing the reviewed Node.js version.
2. Add a Task preflight that rejects runtimes older than Node.js 26.8.1 before npm runs.
3. Route dependency installation and frontend builds through the preflight.
4. Correct `CONTRIBUTING.md` and extend the existing runtime-policy acceptance test.
